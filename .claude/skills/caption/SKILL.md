# Reel caption

Read `site/DESIGN.md` (brand, sections, signature moment) and `docs/RECORDING.md` → hook.

> **Our exact caption format:** not yet written in the kit. Ask the user once to paste it, then replace the "Default format" below with it (keep the short version rule). Until then use the default.

## Default format (until the user's own format is pasted here)
1. **Hook line** (≤ 8 words, no brand name first): what the viewer sees, e.g. *"This energy-drink site cracks open as you scroll."*
2. **What it is** (1–2 short lines): the concept site for <Brand>, the signature moment in plain words.
3. **Built with** (1 line): scroll video · GSAP · WebGL (only what was really used).
4. **Call to action** (from RECORDING.md): *Comment "SITE" and I'll send you the details* / *DM "WEBSITE" to get one for your brand*.
5. **Concept note:** "Concept website, not affiliated with <Brand>." (when a real brand name is used).
6. **Hashtags:** 5–8, niche + web design (#webdesign #scrollytelling #gsap #<niche>), no banned/spam tags.

## Short version
Hook line + CTA + 3 hashtags, ≤ 150 characters, for Stories / cross-posting.

Plain words, no hype words ("revolutionary", "insane"), no emojis spam (max 2), never claim the real brand made it.
